Every day, research GitHub for open-source AI projects that were newly released, significantly updated, or gained meaningful traction within the last 24 hours. Prepare an English “AI Project Newspaper” for me.

The goal is not to provide a generic list of popular repositories. Select projects that are genuinely new, technically strong, practical, and potentially useful for my development as an AI Engineer or for future products and projects I could build.

Prioritize these categories:

- AI agents and agentic workflows
- LLM applications, frameworks, and developer tools
- MCP, tool use, memory, RAG, and agent orchestration
- Multimodal AI: image, video, audio, and computer use
- Local / open-source models and inference tools
- AI tools that improve developer productivity
- Creative open-source products that solve real user problems

Select no more than 5 projects per day. Do not rank projects based only on GitHub stars. Consider all of these criteria:

1. Innovation and originality
2. Meaningful activity in the last 24 hours, such as a release, commit, or rising interest
3. Technical quality and active maintenance
4. Practicality and potential for real-world use or productization
5. Trustworthiness: exclude promotional, cloned, suspicious, or low-quality repositories

Use the following format for each project:

## Project Name — Short category
GitHub: [direct GitHub repository link]

- What does it do?: A simple 2–3 sentence explanation.
- Why is it interesting?: Its technical or product-level differentiator.
- Who is it for?: The target user or developer profile.
- Why is it valuable for me?: Connect it to my AI Engineer path, web development background, automation interests, or possible future product ideas.
- Quick start: The shortest safe setup step or command to try it.
- Things to watch out for: Hardware requirements, API costs, privacy, license, security, or project maturity risks.
- Freshness evidence: Mention the latest release, commit, or verified update date.

Write the newsletter in clear, simple English.

At the end, include these two sections:

## Today’s radar
Briefly explain the most important AI/open-source trend visible today in 2–4 sentences.

## My pick for today
Choose only one project from today’s list that I should inspect or try first. Clearly explain why, and give me a concrete 30–60 minute first-experiment plan.

Avoid repeating projects that were featured on previous days. Only include a previously featured project again if it has received an important release or major update.
